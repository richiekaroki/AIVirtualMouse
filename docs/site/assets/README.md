# Demo Assets

Place your demo GIFs here for the GitHub Pages landing page.

## Required GIFs

| Filename | What to record |
|----------|----------------|
| `demo-enhanced-ui.gif` | The Enhanced UI split-screen with hand tracking, skeleton overlay, and primitive detection |
| `demo-recording.gif` | Press R to record a gesture, show the timer counting, press S to save |
| `demo-analysis.gif` | Run `python MotionAnalyzer.py gesture.json --plot all` and show the plots |

## How to Record

1. **OBS Studio** (free): Add Window Capture source, record 10-15s, convert MP4 to GIF at ezgif.com
2. **ScreenToGif** (Windows, free): Record directly, export as GIF

## Tips

- Keep GIFs under 500 frames for fast loading
- Record at 640x480 or smaller
- Show 10-15 seconds of action
- Use a dark desktop theme for contrast
