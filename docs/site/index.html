Key Features

From raw webcam input to structured motion data in real-time

🎥

Browser Webcam Support

Real-time gesture recognition via WebSocket — no installation required. Works on any device with a camera.

🧠

Dual Gesture Classification

Rule-based (32 finger combinations) + ML-based (RandomForest, 15 gestures) running simultaneously.

💾

Motion Detection

Circle, wave, and swipe recognition from position history. Structured JSON export for ML training.

📈

Analysis & Visualization

Trajectory plots, primitive timelines, velocity profiles, and gesture comparison tools.

🎨

Web UI

Responsive split-screen layout with live skeleton overlay, recording library, and session statistics.

☁️

Render Deployment

One-click deploy with Docker + gunicorn. HTTPS enabled for secure webcam access.

How It Works

Watch the pipeline in action

1

Capture

Browser webcam feed is processed by MediaPipe to extract 21 hand landmarks in real-time via WebSocket.

python -m hand_motion.web.app
2

Classify

Dual classification: rule-based (32 finger combos) + ML-based (RandomForest) run simultaneously.

primitive: POINT · ml: OPEN_HAND · conf: 0.87
3

Record

Save gesture sequences with timestamps. 15 sample recordings included for testing.

wave_sample.json · 60 frames · 2.0s
4

Analyze

Generate trajectory plots, velocity profiles, and primitive timelines from recorded data.

python -m hand_motion.analyzer gesture.json --plot all

Why This Matters

Building infrastructure for sign language translation

Handshape
Captured

Finger states, landmark relationships, handshape encoding (e.g., "11000" for POINT)

Location
Captured

Normalized 2D coordinates, palm center tracking, spatial relationships

Movement
Captured

Velocity vectors, trajectory analysis, temporal primitive sequences

Orientation
Partial

Landmark directions. Planned: 3D orientation from depth data

Planned Extensions

  • Facial expressions (non-manual markers) via MediaPipe Face Mesh
  • Body position context via MediaPipe Pose
  • Two-handed coordination for complex signs
  • Gloss annotation and co-articulation modeling
